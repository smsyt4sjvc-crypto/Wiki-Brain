# mim/ — MONEY IN THE MORNING (rule 16f, set 2026-10-05)

One file per day, built ~9pm PT IN SESSION with `python3 tools/mim.py --new` (never a cron — rule 15).
Shape: graded previous MIM → round-out (bonds · close · macro · market internals · business · war/oil) → ZH since the close (material only) → THE BOOK tonight → 💰 WHERE MONEY GOES AT THE OPEN (calls in the 16e bracket with the precise prediction and the named disconfirmer, or NO TRADE) → not tonight.
Registered at build, graded in the next MIM, never edited. Calls taken are logged in `data/flag_trades.csv`.
