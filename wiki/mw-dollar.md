Curve B: tokens → dollars of model/API revenue — the price curve, and it is deteriorating (paid routed tokens −14% in four weeks; Silicon Data index −52% from May; list prices converging on $2/$10). A single $/token conversion in a MW/$ model hides the divergence. For MW-'s canonical unit (USD millions per effective utilised IT MW-year), the implication is that revenue per MW is set by curve B while MW demand is set by curve A — a data centre can run full and earn less per MW at the same time, which is the "squeeze in the middle" (`metered-compute:L3676`). Series: `data/token_econ/openrouter_weekly.csv` (paid/total). This vault is read-only on MW-; the proposal is recorded here for Jake to carry across.
